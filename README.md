# 考公资讯日报 · 文字版

每天把国考、省考、事业单位的招考公告和报名截止节点做成一份可核对的日报。

视频版只念提要，**全文、原文链接和往期归档都在这个站点**：
视频简介里只放一个地址，就是为了不占满那 200 字的额度，同时让每条都能回原文核对。

## 内容结构

- 首页 `index.html` — 最近若干期的目录
- 每期 `issues/YYYY-MM-DD/` — 该期全部条目的标题、来源、发布时间、摘要、完整正文（可折叠）、原文链接
- `archive/index.html` — 往期归档
- `rss.xml` — RSS 2.0，可直接订阅

## 边界

资讯由 AI 辅助生成并逐条回原文核验，仍可能存在错误，**请以原始信息出处和官方信息为准**。
站内不提供报名入口、不代报名、不做任何形式的考试培训或收费。

## 本仓库怎么来的

由 `kaogong-daily/pipeline/build_site.py` 自动生成，不手工编辑。
每期出片后重跑生成器并推送本目录即可。
